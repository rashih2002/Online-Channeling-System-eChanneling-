# 🏥 Online Channeling System (eChanneling)

A Business Process Management (BPM) project focused on analyzing, improving, and modeling the workflow of an Online Channeling System using BPMN 2.0.

## 📌 Project Description

The Online Channeling System (eChanneling) enables patients to book doctor appointments online, manage payments, receive notifications, and complete consultations efficiently.

This project analyzes the existing appointment booking process and develops an improved business process model that enhances communication, reduces appointment conflicts, and improves the overall patient experience.

The final solution was modeled using Business Process Model and Notation (BPMN 2.0) and visualized using Draw.io.

---

## 🎯 Project Objectives

- Analyze the existing appointment booking workflow.
- Identify process bottlenecks and inefficiencies.
- Design an improved business process.
- Model the process using BPMN 2.0 standards.
- Improve appointment scheduling and cancellation management.
- Enhance communication between patients, doctors, and reception staff.

---

## 🏥 Business Process Scope

### Process Boundary

The process starts when a patient visits the eChanneling platform to book an appointment and ends when the consultation is completed and payment is finalized.

### Stakeholders

- Patient
- Doctor
- Reception Staff
- Online Channeling System

### Inputs

- Patient information
- Doctor availability
- Appointment date and time
- Payment details

### Outputs

- Appointment confirmation
- Payment confirmation
- Reminder notifications
- Cancellation notifications
- Consultation records
- Payment receipts

---

## 🔄 Main Process Flow

1. Patient visits the website.
2. System displays doctor availability and time slots.
3. Patient selects a doctor and appointment slot.
4. Patient enters personal information.
5. Patient selects a payment method.
6. System confirms booking.
7. Confirmation SMS/Email is sent.
8. Reminder notifications are sent before the appointment.
9. Patient arrives at the hospital.
10. Reception verifies appointment details.
11. Doctor conducts consultation.
12. Payment is finalized.
13. Receipt and notification are generated.
14. Process ends.

---

## 🚀 Process Improvements

The improved process introduces:

- Automated SMS notifications
- Automated Email notifications
- Appointment reminder system
- Appointment cancellation workflow
- Alternative time-slot allocation
- Patient and doctor availability verification
- Refund/Cashback handling
- Enhanced communication between stakeholders
